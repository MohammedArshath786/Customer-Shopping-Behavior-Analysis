# Customer Shopping Behavior Analysis Dashboard

## Overview
An Excel-based analysis of retail shopping transactions to understand category contribution, purchase channels, returns and customer review ratings.

## Tools
Microsoft Excel, PivotTables, PivotCharts, Slicers

## Key findings reported
- 10,000 retail transactions
- ₹64.7M total purchase amount; ₹6,468 average order value
- Footwear contributed 58% of spending
- 74% of orders were placed online
- 17.5% of orders were returned
- Average review rating: 3.48 / 5

## File
- `customer_shopping_behavior.xlsx` — Excel workbook containing the analysis/dashboard.

## How to explore
1. Open the workbook in Microsoft Excel (desktop recommended).
2. Use the available PivotTables, charts and slicers to explore the results.
